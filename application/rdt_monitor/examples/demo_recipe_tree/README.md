# Demo recipe tree

This folder is for reviewing the recipe library interface only. All names, article
numbers, batches, thresholds and serials are fictional. Every recipe references
one shared **untrained** OpenVINO mean-score demonstration model. It is not a
trained defect detector and must not be used for real inspection.

Open **Load recipe → Choose folder…** and select this directory. The library
shows two families, four UUTs and six recipe revisions. The camera dimensions,
marker regions and decision thresholds are illustrative and are not qualified.
Keep the detector folder alongside the JSON files when copying this library.
